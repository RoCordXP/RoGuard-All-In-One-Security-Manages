### ROGUARD | All in One Manages/Security
**Updated:**
- This is an upgraded version of **RoGuard 1.3**
- In this version, the plugin has been almost entirely **optimized**
- Removed redundant features to avoid making the plugin too heavy
- Add more **useful features** to the plugin
- Reduced the plugin's file size from **22+ MB** to **18+ MB**
- And supports 7 languages: Vietnamese, Thailand, Chinese, English, Portugal, Spain, Russian

**Auth System:**
- It's just like any other authentication plugin, but it uses Dialog
- However, when players use a version that does not support dialogs, they will enter the game directly and log in by typing in the chat
- But you don’t have to worry about the server **faking coordinates**—which could otherwise lead to losing your base—if the plugin is used on an **SMP server**

**Commands Verify:**
- A system that helps protect **dangerous commands** from being **nuked**
- By sending a verification to a designated **Discord channel**

**Discord Chat Bridge / Console:**
- Like **DiscordSRV** 🙂

**Two Factor Verification:**
- The system added **two layers** of security for players
- Helps if your password is exposed, as there is still a second layer of protection
- By linking your **Discord** account via an in-game command: `/2fa start`

**Anti VPN:**
- The system helps prevent players from accessing the game when using a **VPN**

**Players Manager**
- A system that uses **DiaLog** to manage players
- You can search for most players who have ever joined the server here
- And when you click on any player, all of their information will appear, along with dozens of buttons for you to manage them

**You can turn these functions off in `/roguard settings` or `config.yml`**

See more in: https://modrinth.com/plugin/roguard
